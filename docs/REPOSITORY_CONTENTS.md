# Repository contents and evidence

- `app/` is the executable FastAPI REST + Streamable HTTP MCP implementation.
- `static/` is a local Alexa+-inspired browser demonstration.
- `tests/` has automated API and MCP workflow checks.
- `assets/demo-poster.png` is the project banner.
- `assets/screenshot-{initial,planned,purchased,tasks}.png` are illustrative screenshots from the working local UI.
- `assets/kinship-demo.mp4` is a silent, captioned recording of the local browser demonstration.
- `docs/` explains architecture, the hackathon pitch, demo narration and verification questions.
- `.github/workflows/ci.yml` runs Python tests for pushed commits.

No file in this repository proves a live Alexa+ device connection. Sample prices and household people are fictional. The narrator and public YouTube recording must be supplied or approved by the entrant. This is an AI-assisted scaffold; the entrant is responsible for reviewing all claims and meeting official eligibility and originality rules.
