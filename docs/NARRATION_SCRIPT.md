# Kinship — clear narration script (68 seconds)

The included `assets/kinship-demo-narrated.mp4` uses a slower, **synthetic** voice, not a natural actor. The shorter sentences are designed to be understandable when played on a phone. The silent captioned version is `assets/kinship-demo.mp4`.

| Start | Read this sentence clearly |
| --- | --- |
| 0:00.5 | This is Kinship, a household helper powered by M C P. |
| 0:06.5 | Ask it to plan dinner for four people, for under fifteen dollars. |
| 0:14.2 | It checks the pantry and five recipes. Tonight's choice is chickpea curry. |
| 0:23.5 | Only missing ingredients go on your shopping list. The total is four dollars and ten cents. |
| 0:33.4 | Mark an item as purchased. The pantry and budget update automatically. |
| 0:42.1 | Alex and Sam share cooking tasks. Tick a task when it is done. |
| 0:51.3 | Ask, what is left to do? Kinship remembers your unfinished tasks. |
| 0:59.5 | Eight M C P tools run this demo. It does not connect to Alexa. |

Pronounce *M C P* as separate letters: **em, see, pee**.

Do not claim this is real Alexa+ hardware integration, an LLM agent, live pricing, or a real shopping checkout. This is a self-hosted MCP prototype and browser simulator.

If you want human-quality sound, read this script while playing the captioned silent demo, record through your headset or phone and insert it into a video editor. See `docs/RECORD_YOUR_VOICE.md` for instructions.
