# Final submission checklist — Amazon Developer Hackathon 2026

**Official deadline:** Friday **October 23, 2026 at 12:00 p.m. Pacific** = **Saturday October 24, 2026 at 12:30 a.m. India**.

1. Run the app yourself, test the demo and customize the source/content so you understand it and can honestly represent it as your project. Current project is produced with AI assistance; check the ownership and originality clauses in the rules.
2. Create/log in to a free Devpost account and choose **Join hackathon**: https://amazonappdev2026.devpost.com/
3. Create a GitHub **public** repo `kinship-alexa-mcp` and upload *contents of the project folder* (not the ZIP file by itself). Verify `LICENSE`, code and `README.md` are visible at repo top level. A public MIT repo requires no GitHub judging collaborators.
4. Start the app locally and run `python -m pytest -q`. Confirm the browser UI and MCP demo `python scripts/mcp_demo.py` work.
5. Upload a **public, English** video **under 3 minutes** to YouTube or Vimeo. A demo video file and screenplay are included; if adapting the video, show actual project behavior and not just promotional slides. Never claim official Alexa+ device integration.
6. Create a Devpost submission and paste **docs/DEVPOST_SUBMISSION.md** (after editing to match your experience). Select the **Alexa+** track, paste your actual GitHub URL and the live public YouTube/Vimeo URL.
7. Complete **all required product feedback fields** with genuine feedback; draft in `docs/PRODUCT_FEEDBACK.md`. No fabricated use of inaccessible tools.
8. Check eligibility and terms, especially personal ownership/originality and any existing-employer IP obligations. Submit before deadline and wait for confirmation.
9. Per organizer update, do **not** edit repository, video or project materials after the deadline and before winner announcements.

**Not yet done by this project ZIP:** Devpost registration, public GitHub push, live hosting, public video upload, entrant originality review and submission. Those actions require your own accounts/consent.
